# 📋 Sobre o Projeto

Este projeto foi desenvolvido para a AP2 da disciplina de Big Data e Computação em Nuvem.

A aplicação consiste em uma API REST de um pequeno e-commerce desenvolvida com Django REST Framework e hospedada na AWS utilizando Elastic Beanstalk.

A evolução em relação à AP1 foi a migração da aplicação para uma arquitetura mais próxima de ambientes de produção, utilizando serviços gerenciados da AWS para banco de dados e armazenamento de arquivos.
